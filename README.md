## 🔥 Featured Projects

### 1. 🏥 Skinalyze: AI-Powered Dermatology & Shop Management
*An enterprise-grade medical imaging and product recommendation pipeline.*
- **Tech:** Python, YOLOv11, MedSAM2, Gemini 2.5 VLM, ChromaDB, LangChain.
- **Impact:** Fine-tuned YOLOv11 and MedSAM2 foundation models to segment 11 types of skin lesions. Engineered a RAG pipeline utilizing a verified knowledge base of 1,472 cosmetics, achieving near-zero hallucination for medical/product advice.

### 2. 🌍 Bilingual AI Study Assistant
*A Serverless RAG application for specialized academic translation.*
- **Tech:** Next.js, Supabase (PostgreSQL, pgvector), LLM APIs, Vercel.
- **Impact:** Architected a zero-cost serverless deployment. Implemented RAG via Supabase `pgvector` to query academic lexicons, and designed complex Structured Output prompts to handle translation, terminology extraction, and CEFR evaluation concurrently in a single API request, drastically reducing latency.

### 3. 🏡 Homivn: Peer-to-Peer Accommodation Platform
*A robust full-stack booking system.*
- **Tech:** Python, PostgreSQL, React, FastAPI.
- **Impact:** Engineered a high-performance RESTful API utilizing FastAPI and optimized relational database schemas in PostgreSQL for real-time property matching. Developed a responsive React frontend with efficient state management to ensure a seamless booking experience.
